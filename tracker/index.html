Трекер откликов

Инструмент, которым я веду собственный поиск работы: вакансии, статусы, события и сроки в одном месте. Не учебный пример - рабочая система, где события сами двигают вакансию по воронке.

  • Python
  • FastAPI
  • PostgreSQL
  • SQLAlchemy 2.0
  • REST API
  • Jinja2
  • в ежедневной работе

Как это выглядит

Любой скриншот открывается в полном размере по клику. На скриншотах - демо-данные с вымышленными компаниями: реальная база хранит мой живой пайплайн откликов и остаётся личной.

Что внутри

События двигают воронку

Записал «прислали анкету» - вакансия сама перешла в «скрининг». Девять типов событий, статус всегда отражает последнее реальное действие.

Аналитика по делу

Доля ответов, число дошедших до интервью, отклики без ответа больше недели и ближайшие действия с датами - всё считается на лету.

REST API + интерфейс

FastAPI отдаёт и JSON для API-клиентов, и серверный HTML на Jinja2. Схемы запросов и ответов описаны на Pydantic, документация - Swagger из коробки. Отдельная лента /calendar.ics выгружает созвоны и дедлайны в Google Calendar.

Импорт из заметок

Импортёр разбирает мои markdown-разборы вакансий и переносит их в базу: 26 вакансий заехали одной командой, без ручного ввода.

Модель данных: 4 сущности

Спроектирована под реальный процесс поиска: не «вакансия и точка», а компания, роль в ней, история событий и люди, с которыми идёт общение.
