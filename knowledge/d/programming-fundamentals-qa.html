Ответы на список базовых вопросов (логика, типы данных, функции, ветвления, циклы, рекурсия) — привязаны к C#. Более глубокие смежные темы (value/reference types, коллекции) уже разобраны подробнее в Phase1_CSharp_Fundamentals.md — здесь только то, чего там не было, плюс краткая сводка остального для целостности документа.

1. Что такое true и false в логике

Единственные два значения типа bool — истина и ложь. Основа любого условия и логической операции.

bool isReady = true;
bool hasError = false;

bool canProceed = isReady && !hasError; // true

2. Что такое простые типы данных

Хранят одно неделимое значение напрямую (value types) — int, double, bool, char, decimal. Подробный разбор value vs reference — Phase1_CSharp_Fundamentals.md §1.1.

int age = 28;
double price = 19.99;
char grade = 'A';

3. Что такое сложные типы данных

Составные структуры, собранные из простых типов и/или других сложных: массивы, списки, словари, объекты собственных классов, кортежи.

var user = new { Name = "Ivan", Age = 28 };          // анонимный объект
var pair = (Name: "Ivan", Age: 28);                    // кортеж
List<int> scores = new() { 90, 85, 77 };

4. Что нужно знать о множествах

Множество (set) — коллекция уникальных значений без гарантированного порядка. В C# — HashSet<T> (хеш-based, O(1) в среднем для Add/Contains/Remove) или SortedSet<T> (на дереве, O(log n), но элементы идут по возрастанию).

var a = new HashSet<int> { 1, 2, 3 };
var b = new HashSet<int> { 2, 3, 4 };

a.Contains(2);           // true, O(1)
a.IntersectWith(b);      // a становится {2, 3}
a.UnionWith(b);          // объединение
a.ExceptWith(b);         // разность

Подробнее про HashSet<T> в контексте остальных коллекций — Phase1_CSharp_Fundamentals.md §1.7.

5. Что такое выражение, ветвление и цикл

Три базовых строительных блока любой программы: - Выражение (expression) — вычисляется и даёт значение (2 + 2, x > 5, вызов метода с возвратом). - Ветвление (branching) — выбор одного из путей выполнения (if/else, switch). - Цикл (loop) — повторение блока кода, пока выполняется условие.

int x = 5 + 3;              // выражение → 8
if (x > 5) Console.WriteLine("больше 5");   // ветвление
for (int i = 0; i < 3; i++) Console.WriteLine(i); // цикл

6. Что такое функции и окружение

Функция — именованный блок кода с входом (параметры) и выходом (возвращаемое значение). Окружение (environment/scope) — набор переменных, доступных в текущей точке выполнения: параметры функции, локальные переменные, всё, что "видно" изнутри функции на момент её вызова.

int multiplier = 10; // часть окружения снаружи

int Scale(int x) => x * multiplier; // видит multiplier из внешнего окружения (замыкание)

7. Что такое рекурсия, рекурсивный и итеративный процессы

Рекурсия — функция вызывает сама себя. Но важно различать не синтаксис, а форму процесса, который получается при выполнении:

Рекурсивный процесс — после рекурсивного вызова остаётся отложенная операция (умножение, сложение), поэтому вызовы копятся в стеке, пока не дойдут до базового случая, и только потом "разворачиваются" обратно:

int Factorial(int n) => n <= 1 ? 1 : n * Factorial(n - 1);
// Factorial(4) = 4 * Factorial(3) = 4 * (3 * Factorial(2)) = ...
// умножение ЖДЁТ результат вложенного вызова — растущая цепочка в стеке

Итеративный процесс — состояние целиком передаётся через параметры (аккумулятор), никакой операции после рекурсивного вызова не остаётся — по форме это уже "цикл, просто записанный через вызов функции":

int FactorialIter(int n, int acc = 1) =>
    n <= 1 ? acc : FactorialIter(n - 1, acc * n);
// умножение происходит ДО вызова, не после — ничего не откладывается

Важный нюанс для C# (в отличие от Scheme/F#): .NET JIT не гарантирует оптимизацию хвостовой рекурсии (TCO) — поэтому даже "итеративный по форме" рекурсивный код всё равно может переполнить стек на больших n. Если нужна настоящая защита от StackOverflowException — используйте обычный for/while, не полагайтесь на то, что компилятор сам превратит рекурсию в цикл.

8. Что такое функция и как её создать

// модификатор доступа  тип возврата  имя      параметры
   public              int          Add(int a, int b)
{
    return a + b;
}

// Expression-bodied (C# 6+) — короткая форма для однострочных функций
public int Add(int a, int b) => a + b;

9. Как начать работать с функциями

Вызов передаёт управление внутрь функции, выполнение возвращается к месту вызова после return (или после последней строки для void).

int result = Add(2, 3); // управление уходит в Add, возвращается с result = 5
Console.WriteLine(result);

10. Как задавать аргументы и работать с ними

void Greet(string name, string greeting = "Привет") // значение по умолчанию
    => Console.WriteLine($"{greeting}, {name}!");

Greet("Иван");                    // "Привет, Иван!"
Greet("Иван", "Здравствуй");      // позиционно
Greet(name: "Иван", greeting: "Хай"); // именованные аргументы

void Sum(params int[] numbers) { /* Sum(1,2,3,4) — сколько угодно аргументов */ }

ref/out/in — отдельная тема (передача по ссылке, гарантированная инициализация внутри метода, запрет изменения) — уже разобрана как отдельный вопрос с собеседований в CSharp_Interview_Questions.md.

11. Как работать с локальными и глобальными переменными

Локальная переменная — существует только внутри блока, где объявлена (метод, if, for). "Глобальная" в классическом C# отсутствует буквально — ближайший аналог — static поле класса, видимое отовсюду через имя класса.

class Counter
{
    public static int GlobalCount = 0; // "глобальная" — общая на всё приложение

    public void Increment()
    {
        int local = 1; // видна только внутри Increment
        GlobalCount += local;
    }
}

Локальная переменная с тем же именем, что и поле класса, затеняет (shadowing) его внутри своего блока — доступ к полю тогда нужен через this..

12. Как документировать функцию и возвращать несколько значений из функции

Документирование — XML doc comments (///), IDE подхватывает их в подсказках:

/// <summary>Считает сумму двух чисел.</summary>
/// <param name="a">Первое слагаемое</param>
/// <param name="b">Второе слагаемое</param>
/// <returns>Сумма a и b</returns>
public int Add(int a, int b) => a + b;

Несколько значений из функции — три варианта, от простого к строгому:

// 1. Tuple — быстро, но менее самодокументируемо
(int min, int max) FindMinMax(int[] nums) => (nums.Min(), nums.Max());
var (min, max) = FindMinMax(new[] { 3, 1, 9 });

// 2. out-параметры — привычно из TryParse-стиля
bool TryDivide(int a, int b, out int result)
{
    if (b == 0) { result = 0; return false; }
    result = a / b;
    return true;
}

// 3. record — когда значений много и важна читаемость (предпочтительно)
record MinMaxResult(int Min, int Max);
MinMaxResult FindMinMax2(int[] nums) => new(nums.Min(), nums.Max());

13. Как работать с конструкциями

"Конструкции" языка — это условия, циклы и функции вместе: строительные блоки, из которых собирается любая программа. Работа с ними — это их комбинирование: функция содержит внутри себя ветвления и циклы, циклы могут содержать вызовы функций, и так далее, слоями.

14. Что такое условия и как с ними работать

int score = 75;

if (score >= 90) Console.WriteLine("Отлично");
else if (score >= 75) Console.WriteLine("Хорошо");
else Console.WriteLine("Нужно подтянуть");

15. Как использовать условные операторы в функциях и комбинировать условия

&& (И), || (ИЛИ), ! (НЕ) — с коротким замыканием (short-circuit): если левая часть && уже false, правая не вычисляется вообще.

bool CanWithdraw(decimal balance, decimal amount, bool accountActive)
    => accountActive && balance >= amount && amount > 0;
    // если accountActive == false — остальное даже не проверяется

16. Что такое тернарный оператор

Сокращённая форма if/else, которая сама является выражением (возвращает значение):

string status = age >= 18 ? "взрослый" : "несовершеннолетний";
// эквивалент:
// string status; if (age >= 18) status = "взрослый"; else status = "несовершеннолетний";

17. Как использовать условный оператор в коде: методика раннего прерывания

Early return / guard clause — выйти из функции сразу, как только условие делает дальнейшую работу бессмысленной, вместо вложенных if:

// ПЛОХО — вложенность растёт с каждым условием
void Process(User? user)
{
    if (user != null)
    {
        if (user.IsActive)
        {
            // основная логика тут, на 3-м уровне вложенности
        }
    }
}

// ХОРОШО — guard clauses, основная логика на верхнем уровне
void Process(User? user)
{
    if (user is null) return;
    if (!user.IsActive) return;

    // основная логика тут, плоско
}

18. Как избегать длинных условий в коде

Выносить куски условия в переменные или методы с говорящим именем — само условие превращается в читаемое предложение:

// ПЛОХО
if (user.Age >= 18 && user.HasVerifiedEmail && !user.IsBanned && user.Country == "RU")

// ХОРОШО
bool isEligible = user.Age >= 18 && user.HasVerifiedEmail;
bool isAllowed = !user.IsBanned && user.Country == "RU";
if (isEligible && isAllowed)

19. Как избегать дублирований

Принцип DRY (Don't Repeat Yourself) — повторяющийся код выносится в отдельный метод/функцию один раз, а не копируется:

// ПЛОХО — одна и та же формула скопирована трижды
double a1 = width1 * height1 / 2;
double a2 = width2 * height2 / 2;
double a3 = width3 * height3 / 2;

// ХОРОШО
double TriangleArea(double w, double h) => w * h / 2;
double a1 = TriangleArea(width1, height1);

20. Как не усложнять код

Принцип KISS (Keep It Simple) — из двух одинаково рабочих решений выбирать более простое и читаемое, а не более "умное". Признаки переусложнения: слишком общая абстракция под единственный текущий сценарий, вложенность больше 2-3 уровней, метод длиннее экрана. Простой, скучный код, который сразу понятен — лучше, чем эффектный, но требующий разбора.

21. Что такое циклы в C# и как с ними работать

// for — когда известно количество итераций
for (int i = 0; i < 5; i++) Console.WriteLine(i);

// foreach — перебор коллекции без ручного индекса
foreach (var item in new[] { "a", "b", "c" }) Console.WriteLine(item);

// while — пока условие истинно, проверка ДО тела
while (queue.Count > 0) Process(queue.Dequeue());

// do-while — тело выполнится минимум 1 раз, проверка ПОСЛЕ
do { attempt++; } while (attempt < maxAttempts);

// break — досрочный выход, continue — пропуск текущей итерации
foreach (var n in numbers)
{
    if (n < 0) continue;   // пропустить отрицательные
    if (n > 100) break;    // остановиться на первом > 100
    Console.WriteLine(n);
}

22. Что такое рекурсии в C

Функция, вызывающая саму себя, с обязательным базовым случаем (иначе — StackOverflowException):

int Fibonacci(int n)
{
    if (n <= 1) return n;            // базовый случай — останавливает рекурсию
    return Fibonacci(n - 1) + Fibonacci(n - 2); // рекурсивный случай
}

См. пункт 7 выше — важно понимать разницу между рекурсивным и итеративным процессом, и что C# не гарантирует TCO.

23. Как работать с лямбда-функциями в C

Лямбда — короткая безымянная функция, чаще всего используется там, где нужно передать "поведение" как аргумент (LINQ, обработчики событий, делегаты).

// Синтаксис: (параметры) => выражение_или_блок
Func<int, int, int> add = (a, b) => a + b;
Action<string> log = msg => Console.WriteLine(msg);
Predicate<int> isEven = n => n % 2 == 0;

// Самое частое применение — внутри LINQ
var evens = new[] { 1, 2, 3, 4 }.Where(n => n % 2 == 0).ToList();

// Захват переменных из окружения (closure) — см. пункт 6
int threshold = 10;
Func<int, bool> aboveThreshold = n => n > threshold; // захватила threshold

Подробнее делегаты (Func/Action/Predicate) и multicast-делегаты — Phase3_Advanced.md §3.2.
