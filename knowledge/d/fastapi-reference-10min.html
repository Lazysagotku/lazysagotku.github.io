FastAPI — справка на 10 минут

58 строк · источник l2code/FastAPI_Reference_10min.md

Теория, не практика. Специально мапится на то, что ты и так учишь в ASP.NET Core — почти всё узнаешь как знакомое, просто под другим именем.

Что это

FastAPI — современный Python-фреймворк для API, построен на Starlette (ASGI, т.е. async-first) + Pydantic (валидация данных через типы). Появился в 2018, сейчас — стандарт для нового Python-backend наравне с Django.

Чем отличается от того, что уже знаешь (Flask/Django)

Flask Django FastAPI
Async Опционально, не по умолчанию Традиционно sync (Django REST Framework — отдельно) Async по умолчанию
Валидация запросов Вручную Через сериализаторы DRF Автоматически, через типы Python
Документация API Вручную (Flask-Swagger) Вручную Автогенерация Swagger/OpenAPI из кода
DI Нет встроенного Нет встроенного Встроенная система Depends()

Мапинг на ASP.NET Core — вот почему это должно быть легко

ASP.NET Core (учишь сейчас) FastAPI (эквивалент)
DTO класс + DataAnnotations Pydantic модель — тот же класс с типами полей, та же роль (валидация + сериализация)
Constructor injection (DI) Depends() — та же идея, другой синтаксис
[HttpGet("route")] + маршрутизация @app.get("/route") декоратор
async Task<IActionResult> в контроллере async def endpoint(...)
Swagger/Swashbuckle настройка вручную Автоматически из типов, без настройки
Middleware pipeline @app.middleware("http") — та же идея

Зачем это вообще нужно знать

На рынке Python (см. анализ рынка ранее) связка Django + FastAPI + asyncio даёт максимум на собесе — Django для "тяжёлых" приложений с админкой, FastAPI для чистых API и микросервисов. Достаточно знать ЧТО это и ЧЕМ отличается — не строить на нём проект сейчас.

Итог: это не новая парадигма — это ASP.NET Core концепции (DI, DTO, middleware, автодокументация) в питоновской обёртке. Если разберёшься в ASP.NET Core (а мы туда идём), FastAPI прочитается почти без усилий, когда реально понадобится.
