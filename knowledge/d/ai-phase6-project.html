🏗️ Фаза 6. Прикладной проект (5 часов)

69 строк · источник l2code/AI_Phase6_Project.md

📖 Фаза роадмапа «AI Product Engineer». Оглавление и статус - в AIEngineer_Roadmap.md. Каждая фаза самодостаточна: 🎭 аналогия → 📖 теория → 🔧 практика → 💥 сломай намеренно → ✅ задание → 🌍 из жизни → ❓ вопросы с ответами.

Цель: не учебный пример, а фича, которая реально используется каждый день.

🎭 Аналогия

Разница между тренировкой и матчем. В тренировке важно правильно выполнить упражнение, в матче - результат. Проект этой фазы - то, что ты открываешь каждый день, а не то, что лежит в репозитории для показа.

📖 Что собираем

Помощник по базе знаний - собирает всё из предыдущих фаз на реальных данных:

Из фазы Что вносит
1 структура промптов, честность про ограничения
2 структурированный вывод, кэш префикса, учёт стоимости
3 поиск по 79 документам базы знаний через pgvector с гибридом
4 MCP-сервер, чтобы пользоваться из Claude Code
5 набор для оценки, логирование, версии промптов

Почему именно это. База знаний уже собрана, документы свои, вопросы к ним возникают каждый день во время подготовки к собеседованиям. Проект не придётся заставлять себя использовать.

Что должно получиться

  1. Вопрос на естественном языке - ответ с цитатами и ссылками на исходные документы.
  2. Ответ «в моих документах этого нет», когда действительно нет.
  3. Доступ из Claude Code через свой MCP-сервер.
  4. Веб-страница в портфолио с работающим поиском.
  5. Панель со статистикой: запросы, задержка, стоимость.

🔧 Практика

  1. Собрать конвейер: индексация базы знаний, гибридный поиск, генерация ответа с цитатами.
  2. MCP-сервер с инструментом search_knowledge, подключить к Claude Code.
  3. Страница поиска в портфолио.
  4. Набор из 30 вопросов, замер Recall@5 и точности ответов.
  5. Логирование в таблицу, панель в Grafana.
  6. Повторы, лимит стоимости на запрос, работа при недоступности модели - отдать найденные фрагменты без генерации.

💥 Сломай намеренно

  1. Спросить о том, чего в документах нет - убедиться, что приходит «не нашёл», а не выдуманный ответ.
  2. Отключить модель и проверить, что поиск продолжает отдавать фрагменты.
  3. Задать вопрос с точным термином из документа и проверить, что гибрид его находит.
  4. Убрать лимит стоимости и задать вопрос, требующий большого контекста.

✅ Задание

Работающий помощник, которым пользуешься при подготовке к собеседованиям. Опубликован в портфолио. В README - цифры: объём корпуса, Recall@5, средняя задержка, стоимость запроса.

Критерий: можешь провести человека по всей цепочке от вопроса до ответа и объяснить каждое решение.

🌍 Из жизни

Про проекты, которыми не пользуются. Портфолио с демо, которое автор сам не открывает, видно на собеседовании сразу: на вопрос «а как оно ведёт себя на таком случае» ответа нет. Проект, используемый ежедневно, отвечает на такие вопросы сам.

Про деградацию. Модель недоступна - помощник обязан отдать хотя бы найденные фрагменты. Это то же правило, что с кэшем в фазе 7 Python-роадмапа: вспомогательный компонент не роняет систему.

❓ Вопросы с ответами

Расскажите про свой AI-проект.

Помощник по собственной базе знаний: 79 документов, гибридный поиск через pgvector с полнотекстовым, ответ с цитатами и ссылками на источники. Доступен через свой MCP-сервер из рабочего окружения и страницей в портфолио. Есть набор для оценки на 30 вопросов, логирование вызовов и панель со стоимостью. Пользуюсь им сам при подготовке.

Что было самым сложным?

Chunking. Выбор модели эмбеддингов дал меньше, чем переход от резки по размеру к резке по заголовкам с перекрытием. И понимание, что без набора вопросов улучшать нечего - любая правка была бы ощущением.
