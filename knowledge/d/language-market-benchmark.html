Language Market Benchmark - C#, Python, Go, Java, TypeScript, Rust

323 строк · источник l2code/LANGUAGE_MARKET_BENCHMARK.md

Заказано 15.09.2026 по итогам независимого review (уточнение к OPEN_LOOPS.md №3). Явное условие заказчика: C#/.NET не убирается из роадмапа и не маркируется заброшенным. Иван подтвердил, что язык ему нравится и он считает его сильным инструментом, но решение должно приниматься по данным рынка, а не по симпатии. Стратегическая рамка задачи: инфраструктура/эксплуатация остаётся текущим основным треком; C#/.NET сохраняется как стратегический backend-актив; горизонт расширен до международного remote и релокации (в первую очередь Германия) - выбор языка нельзя оптимизировать только под российский рынок.

Как читать этот документ

Три рынка (A - Россия, B - global/international remote, C - relocation/Германия+ЕС), шесть языков, набор критериев по каждому. Числа - из открытых источников на сентябрь 2026, с датой и ссылкой у каждого блока. Там, где источники расходятся или число примерное - явно написано «диапазон» и «оценка», а не выдуман один точный факт.

Честное ограничение исследования. Прямой доступ к hh.ru API и к hh.ru через поисковый веб-инструмент из этой сессии заблокирован их собственной защитой от VPN (та же проблема, с которой Иван сталкивался при попытках автоматизировать Разведчика). LinkedIn/Indeed/Glassdoor не отдают агрегированную статистику по запросу без учётной записи и API-ключа, которых у меня нет. Поэтому данные по рынку A и по глобальному remote-рынку взяты из вторичных источников - обзоров Хабр Карьеры, агрегаторов зарплат (enigmai.ru, checkroi.ru), профильных рекрутинговых блогов и открытых отчётов (JetBrains, GitHub Octoverse, Stack Overflow). Это не первичные данные, и там, где агрегаторы противоречат друг другу, это указано.

Гипотеза, которую проверяем

«Go может быть мостом между infrastructure/cloud/distributed systems и backend, а C# может оставаться сильным enterprise/backend активом.»

Короткий ответ по итогам исследования - гипотеза подтверждается данными, с одной поправкой: Go даёт синергию с уже идущим инфраструктурным треком гораздо дешевле по времени, чем любой другой новый язык в списке, потому что весь инструментарий cloud-native (Docker, Kubernetes, Terraform, Prometheus) написан на Go и Иван и так его изучает как пользователь. C# остаётся сильным и стабильным enterprise-активом, но не показывает признаков нового взрывного роста ни на одном из трёх рынков - его роль не «расти», а «не терять». Подробный разбор - в разделах ниже и в итоговом скоркарде.

Рынок A - Россия

Общий фон

Медианная зарплата разработчика в России - 182-183 тыс. ₽ (Хабр Карьера, данные за 2025 год)1. Вилка для специалиста 1-3 года по hh.ru - 129-280 тыс. ₽1. Архитекторы ПО - топ по доходу: 420-508 тыс. ₽ в зависимости от города1. Рынок вакансий по hh.ru в 2026 году активно анализировался в открытых постах на Хабре (десятки тысяч вакансий за раз), но сам hh.ru прикрыл открытый API примерно в апреле 20262 - актуальных сплошных выгрузок за лето-осень 2026 в открытом доступе нет, только выборочные обзоры отдельных языков.

Вывод по рынку A: Go - единственный язык из списка с явной положительной динамикой зарплаты и структурным дефицитом кадров в России прямо сейчас. C# и Java - стабильное плато, не падение, но и не рост. TypeScript обязателен для фронтенд/фуллстек-сегмента, но это не профиль Ивана (эксплуатация/backend). Rust - реальный, но узкий рынок, почти весь в Москве и в нескольких компаниях уровня Яндекса.

Рынок B - Global / international remote

Источники по языкам в целом

GitHub Octoverse 20257: в августе 2025 TypeScript впервые обогнал Python и JavaScript по числу активных контрибьюторов на GitHub (2,64 млн, +66,6% год к году) - самый резкий сдвиг за десятилетие, связанный с тем, что типизация лучше работает с AI-агентами и Copilot, и с тем, что TypeScript стал дефолтом в scaffolding крупных фреймворков. Python остаётся лидером именно в AI/data science. C# на 5-м месте по абсолютному приросту контрибьюторов год к году (+136 735, +22,2%) - это сильный, растущий сигнал не про хайп, а про реальное расширение аудитории.

JetBrains State of Developer Ecosystem 20258 (24 534 разработчика, апрель-июнь 2025): наивысший «growth potential» (Language Promise Index) - у TypeScript, Rust и Go. JavaScript, PHP и SQL - «плато зрелости». Языки, которые разработчики больше всего хотят выучить: Go (11%), Rust (10%), Python (7%), Kotlin (6%), TypeScript (6%) - C# и Java в этом списке желаний не попали в топ-5, что говорит не о падении, а об отсутствии «хайпа» вокруг них - предсказуемо для зрелых enterprise-языков.

Stack Overflow Developer Survey 20259: JavaScript - самая используемая технология (66%), Rust восьмой год подряд - «most admired» язык.

Remote-специфика

Компьютерные/IT-вакансии - самая быстрорастущая категория remote-постингов, удвоение quarter-over-quarter по одному источнику11. Общий вывод из нескольких источников: «skill matters more than location now, but competition is global too»11 - то есть remote снимает географический барьер, но конкуренция за эти позиции идёт с разработчиками из низкозатратных регионов по всему миру, не только внутри России.

Вывод по рынку B: Go имеет лучшую комбинацию «зарплата + дефицит + растущий спрос» из всех шести языков. TypeScript - структурный лидер по объёму рынка и единственный язык с прямой связкой к AI-tooling экосистеме (агенты лучше работают с типизированным кодом). C# - крепкий средний сегмент со стабильным ростом числа разработчиков, но не входит в языки с «growth potential» или «desire to learn» по опросам - это рынок для тех, кто уже внутри, не точка входа для хайпа. Rust - реальный, но статистически шумный и объективно маленький рынок.

Рынок C - Relocation / Германия и ЕС

Ключевой вывод, который меняет рамку вопроса

Немецкая система разрешений на работу для IT (EU Blue Card) устроена по профессии (код ISCO-08), не по языку программирования13. Список профессий с пониженным порогом Blue Card на 2026 год включает: 2511 системные аналитики, 2512 разработчики ПО, 2513 веб/мультимедиа-разработчики, 2514 программисты-прикладники, 2519 IT-специалисты прочие, 2521 проектировщики баз данных, 2522 системные администраторы, 2523 специалисты по компьютерным сетям13. Стандартный порог зарплаты для Blue Card в 2026 - €50 700/год, для профессий из списка дефицитных - ниже, €45 934,20/год13.

Это прямо касается текущего направления Ивана - роли «инженер сопровождения» и «системный администратор» с кодами 2522/2523 попадают в льготный список наравне с разработчиками. Для IT-специалистов диплом не обязателен при 3+ годах подтверждённого опыта за последние 7 лет1314 - у Ивана это условие уже выполнено семью годами в поддержке.

Практический вывод: язык программирования вторичен для самого факта релокации в Германию по этому пути - первичен код профессии и опыт. Язык программирования становится значим на следующем шаге - какие конкретно вакансии внутри «Software Developer»/«System Administrator» реально доступны и какая у них зарплата.

Зарплаты и рынок труда в Германии

Средняя зарплата разработчика ПО в Германии - €53 988/год (2026)15. Junior - примерно €41 000-55 00015. По регионам: Штутгарт €51 300-70 700, Берлин €46 900-65 50015. Важное наблюдение: порог Blue Card по дефицитным профессиям (€45 934) ниже среднего junior-диапазона в Берлине - то есть попадание под льготный порог реалистично уже на входном уровне, если удастся получить job offer.

Германия официально признаёт нехватку кадров в IT/STEM как один из главных дефицитных секторов (163+ профессий в списке бутылочных горлышек на 2025-2026, включая IT/инженерные)13. Спрос устойчивый, международный найм в IT - обычная практика (пример из источника: в берлинском офисе 40 человек штат из СНГ стал нормой, работодатели помогают с документами и переездом)16.

Требования к языку: английский на уровне B1+ обычно достаточен для самой работы, немецкий не обязателен, но B1 немецкого сокращает путь к ПМЖ через Blue Card до 21 месяца против 27-33 без него1416.

Языковой профиль спроса в Германии

Прямых языковых срезов (сколько именно вакансий на C# vs Go vs Python в Германии) в собранных источниках нет - это требует отдельного прохода по немецким job-бордам (StepStone, Indeed.de) в следующей итерации. Косвенно: C# и Java исторически сильны в немецком enterprise/финтех/автопроме (SAP-экосистема, банки, страховые), Python - в data/ML, Go - в cloud-native/инфраструктурных ролях у более молодых технологических компаний и части enterprise, переезжающего в облако.

Вывод по рынку C: relocation-потенциал для текущего профиля Ивана (эксплуатация + инфраструктура) уже сейчас выше, чем можно было бы предположить по одному только языку программирования - профессия «системный администратор» / «инженер эксплуатации» официально льготная. Освоение Go или укрепление C# расширяет спектр доступных ролей внутри этого льготного коридора, но не является условием самой релокации.

Итоговые рейтинги

1. Локальный рейтинг (Россия)

  1. Python - самый широкий и растущий рынок, уже сильная сторона Ивана.
  2. Go - лучшая зарплатная динамика, структурный дефицит кадров.
  3. TypeScript - большой и растущий рынок, но не про профиль Ивана (фронтенд/фуллстек).
  4. C# / Java - стабильное плато, без роста и без падения.
  5. Rust - реальный, но маленький и сконцентрированный рынок.

2. Global рейтинг

  1. TypeScript - структурный лидер по объёму и росту, усиленный AI-tooling трендом.
  2. Python - доминирует в AI/data, широкий рынок.
  3. Go - лучшая зарплатная премия за счёт дефицита, сильный рост.
  4. C# - стабильный крупный рынок с реальным ростом числа разработчиков (+22% YoY по Octoverse), но не «горячий».
  5. Java - зрелый, стабильный, без явного отличия от C# по динамике.
  6. Rust - «most admired», но объективно маленький рынок вакансий.

3. Relocation рейтинг (Германия/ЕС)

Профессия важнее языка (см. раздел про рынок C). При равной профессии («разработчик» / «системный администратор» - оба льготные): 1. Python и Go - лучше всего ложатся на профиль «инфраструктура/эксплуатация», который у Ивана уже льготный по коду занятия. 2. C#/Java - доступны через классический enterprise/финтех-найм в Германии, требуют отдельного изучения немецких вакансий по стеку (не сделано в этой итерации - см. ограничения). 3. TypeScript - доступен через fullstack-роли, не основной профиль Ивана. 4. Rust - самый узкий канал, скорее исключение, чем стратегия.

4. Рейтинг персонально для Ивана (с учётом накопленного C#/.NET и текущего инфраструктурного трека)

Это единственный рейтинг, где «дешевизна перехода» и «синергия с уже идущим треком» весят так же много, как абстрактный размер рынка:

  1. Python - уже есть, уже растёт, прямая синергия с текущим треком. Поддерживать активно, это не новая инвестиция.
  2. Go - лучшее соотношение «новое усилие / отдача»: рынок растёт, зарплата выше средней, а изучение почти бесплатно поверх уже идущего Kubernetes/Docker/Linux трека. Главная рекомендация этого исследования.
  3. C#/.NET - не расти вширь, но не бросать: 7 лет опыта - невозобновляемый актив, рынок стабилен, а не падает, и остаётся резервным enterprise-треком, если инфраструктурная стратегия не сработает или если появится конкретная сильная вакансия. Именно это и просил зафиксировать Иван.
  4. TypeScript - низкий приоритет сейчас: нет синергии с профилем эксплуатации, но и не вреден - минимальное знакомство не помешает при fullstack-задачах на портфолио.
  5. Java - не изучать: та же ниша, что C#, без синергии с текущим треком, дублирует уже занятую нишу без нового рынка взамен.
  6. Rust - не изучать сейчас: слишком высокий порог входа при слишком узком рынке относительно других приоритетов.

5-7. Языки: изучать / поддерживать / не трогать

  • Изучать (новая инвестиция времени): Go. Единственный язык, который проходит тест «дешёвая синергия + растущий рынок + прямое усиление relocation-профиля».
  • Поддерживать (не терять, не наращивать активно): C#/.NET, Python. Python - потому что уже используется каждый день (скрипты, Скаут, Трекер) и растёт сам по себе без выделенного времени. C# - потому что это стратегический актив, который Иван прямо просил не терять; поддержание = периодическая практика и держать язык «в тонусе», не полноценный второй трек обучения.
  • Не трогать сейчас (сознательно, не по незнанию): Java (дублирует нишу C# без нового рынка), Rust (высокий порог, узкий рынок, нет срочности), TypeScript (нет синергии с текущим профилем; если понадобится для конкретного fullstack-проекта - изучать точечно под задачу, не как отдельный трек).
