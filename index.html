Тикет-система, после которой первая линия поддержки стала лишней Мосгоргеотрест

Спроектировал и внедрил внутреннюю тикет-систему и настолько её отладил, что отдельная 1-я линия оказалась ненужной: маршрутизация, права по группам пользователей и автозаполнение делали рутинную работу сами. Позже собрал на той же базе кадровую систему с разграничением доступа.

Импорт заявок в Jira: больше года в проде ТРИНФИКО

Цепочка из шести Python-скриптов переносит заявки из внутренней тикет-системы в Jira: выгрузка, CSV, загрузка, статус на каждом шаге. Пользуется вся группа поддержки, а руководство импортирует задачи самостоятельно, без участия разработчика.

TimeReportV3: соло-доработка легаси-инструмента учёта заявок ТРИНФИКО

В одиночку развивал внутренний WinForms-инструмент, доставшийся как легаси: двойная интеграция с IS-системой и Jira через Dapper, поддержка PostgreSQL и MS SQL. Фича «фильтрация заявок по сервисам» - с README, где четыре пойманных бага разобраны до root-cause: гонка BeginInvoke, перерисовка DataGridView и другие.

«Электронный секретарь» с отчётами в Telegram Мосгоргеотрест

Сервис на React и Python: многопоточные сессии, мониторинг через Selenoid, о каждом успехе и сбое сам докладывает в Telegram-бот. Плюс автоматизация отчётности для руководства: из ручной выгрузки JSON вырос гибкий конструктор отчётов.
